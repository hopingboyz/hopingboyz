### 🎮 Minecraft Server Management

I work on tools designed to simplify Minecraft server administration and hosting.

Some areas I explore include:

- 📊 Real-time server statistics and status monitoring.
- 🖥️ Interactive server consoles with live output.
- 🎨 ANSI colors, Minecraft formatting codes, and readable logs.
- 📁 Server file and world management.
- 🔌 Plugin management and installation.
- ☕ Java version management and server deployment.
- 🌐 Multi-node infrastructure and resource allocation.
- ⚡ Real-time communication using Socket.IO.

My aim is to create a clean, modern, and practical server management experience.

### 🐳 Virtualization & Infrastructure

I'm passionate about building and managing server environments using modern virtualization and container technologies.

Areas of interest include:

- Proxmox VE virtualization.
- Linux server administration.
- Docker containers and containerized applications.
- QEMU-based virtual machines.
- Incus and Linux container management.
- Networking, IP allocation, and resource management.
- Reverse proxies, DNS, and Cloudflare integration.
- Automated deployments and infrastructure monitoring.

### 🤖 Discord Bots & Automation

I also explore Discord bot development to automate repetitive tasks and connect communities with hosting infrastructure.

My projects may include VPS management commands, automated provisioning workflows, server status reporting, and interactive administration interfaces.
